# 离线 GNSS 地图

版本：0.1
状态：需求已决定，渲染技术待 ADR/原型验证

## 1. 必须满足

- 无互联网时轨迹、当前位置和道选择仍可工作。
- 不运行时下载 `unpkg` 等 CDN 脚本。
- 在线瓦片不可用时自动降级到本地资源或无底图坐标画布，不影响采集。
- 不把地图渲染放在 GNSS reader 或地面 ingest 线程。
- 地图故障不影响原始 GNSS 保存和任务状态。

## 2. 渲染技术候选

实现前用小型原型和 ADR 比较：

- Qt 原生/QML 地图或自绘轨迹；
- Qt WebEngine 加随软件分发的本地 HTML/JS 与离线瓦片；
- 其他许可和 Windows 打包可控的离线组件。

选择维度：离线完整性、包体、许可、DPI、GPU/CPU、十万点性能、点击命中、崩溃隔离和 Windows 部署。不得因为原型方便直接复制旧 UAV-GPR 的在线页面。

## 3. 数据接口

地图控件只接收展示模型：

- `MapTrackSegment`：有序有效坐标与 trace UID；
- `CurrentPosition`：当前有效 fix 或明确不可用；
- `SelectedTrace`；
- `ViewportCommand`：follow/fit/zoom；
- `MapSourceStatus`：offline/online-disabled/blank/error。

它不直接读取串口、`.rcscan` 或网络消息。

## 4. 投影和精度

- 存储保持 WGS84。
- 常规瓦片显示可使用 Web Mercator，但高纬限制和显示误差需记录。
- 无底图模式至少提供经纬网、比例尺、北向、轨迹和边界。
- 轨迹选择返回 `trace_uid`，不能根据屏幕最近点擅自改写原始位置。

## 5. 长轨迹性能

- 不为每一道创建永久 QObject/Web marker。
- 使用折线批次、分段缓存和视口相关抽稀。
- 当前/选中道保留精确点；普通轨迹可只在显示层抽稀，原始点不删除。
- GNSS 可能高于雷达采样频率，主轨迹显示和“每道位置”图层分开。
- 地图刷新建议限频，不随每条 NMEA 立刻重排全部轨迹。
- 10 万道合成数据作为基准；缩放、选择和跟随期间 UI 保持可响应。

## 6. 地图资源

- 本地瓦片/矢量数据必须登记来源、许可、覆盖区域、坐标系、版本和更新时间。
- 现场缓存与项目资源分离并默认不提交 Git。
- 缓存有最大容量和清理策略；清理不得触及 `.rcscan`。
- 未授权瓦片不得打包发布。
- 在线访问默认关闭；如后续启用，设置中明确数据/隐私影响。

## 7. 失效呈现

- `no_fix`：隐藏当前位置，保留历史轨迹并显示“无定位”。
- `stale`：最后点可作为历史点，但不能继续显示实时脉动/跟随。
- 底图错误：切换无底图模式，状态栏告警，不弹窗阻断采集。
- 无 GNSS 的 trace：B-scan 选择仍成立，地图显示“该道无位置”。

## 8. 测试

- 完全禁网环境启动和使用。
- CDN/DNS/瓦片失败时无长时间 UI 卡顿。
- 跨经度边界、相同坐标、无效坐标、轨迹断点。
- 十万道缩放/选择/跟随和内存基准。
- B-scan 到地图、地图到 B-scan 的 trace UID 联动。
- 地图控件异常不终止采集/地面存储 worker。
