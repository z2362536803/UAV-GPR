## 4. 设计决策（D1–D9）

- **D1 stage 契约复用**：`FrequencyToTimeStage` 结构化实现 030 冻结的 `ProcessingStage` Protocol（`stage_name="frequency_to_time_ifft"`、`stage_version="1.0"`、`input_domain=frozenset{raw,calibrated,background_applied,filtered}`、`output_domain=time_base`），import 尾部 `assert isinstance(...)` 静态防漂移；history 追加一律走 `ProcessingHistory.append`（链式校验 + 同 history stage 唯一由 core fail-closed 强制），不建平行 history。
- **D2 输出容器与返回类型**：core 无单扫时域容器（`TimeDomainScan` 是唯一 time 模型且强制 3-D trace×channel×time），故 sweep 输入产出单 trace scan（`data[np.newaxis,...]`、metadata=()），scan 输入保持 trace 数；030 的 `StageResult.source` 运行时限定频域容器，因此本模块提供同形姊妹类 `TimeDomainStageResult(source: TimeDomainScan, history, domain)`（三字段形状一致，协议方法签名兼容）。输入域判定同 D2(030)：由调用方传入 history 末条输出域决定（空 history = frequency_raw）。
- **D3 均匀轴校验（PROCESSING §4 第 5 条）**：`validate_uniform_axis` 在 core 保证（有限/严格递增/实数 1-D）之上补：≥2 点、非负频率（`OUT_OF_RANGE`）、重复/递减哨兵（`NON_INCREASING_AXIS`）、逐步进与中位步进偏差 ≤ `max(1 Hz, |Δf|·1e-6)`（与参考逐字同容差），超差 → `NON_UNIFORM_AXIS` 拒绝——非均匀轴绝不悄悄套普通 IFFT；容差内边缘样例显式测试接受行为。
- **D4 补零网格数学（迁移参考契约）**：`first_bin = max(0, round(f_start/Δf))` 最近 bin 对齐；`[0, first_bin)` 低频补零（显式策略键 `zero_padding_policy=dc_to_start_low_frequency_zeros`）；剩余 sub-bin 频偏 `offset = f_start − first_bin·Δf` 在 IFFT 后乘相位斜坡 `exp(2jπ·offset·t)` 恢复（与参考逐字一致，保科学结果相同）；FFT 长度默认 `next_pow2(first_bin+n)·oversampling`（默认 oversampling=16，显式记录），亦支持绝对 `fft_size`（必须 2 的幂且 ≥ padded_length，否则 `INVALID_ARGUMENT`/`OUT_OF_RANGE`）；时间轴 `arange(N)/(N·Δf)` 秒，覆盖完整周期 T=1/Δf（末样本在 T−dt）。沿最后一维一次 `np.fft.ifft(axis=-1)` 向量化（trace×channel 全批量，广播置入 padded）。
- **D5 参数规范化（JSON-safe、单位显式）**：record parameters = 配置层 {grid, zero_padding_policy, oversampling_factor, fft_size_mode, explicit_fft_size(None 合法), interpolation_only_no_physical_resolution_gain, time_axis_unit:"s", archived_window, physical_period_formula, depth_calculation:false} + 每次运行派生层 {frequency_delta_hz, frequency_point_count, start/stop_frequency_hz, low_frequency_zero_bins, aligned_grid_start_hz, start_frequency_offset_hz, fft_size, time_sample_interval_s, physical_unambiguous_period_s}；测试断言 to_dict/from_dict 往返相等与 canonical JSON 关键子串。
- **D6 时间与版本**：`executed_utc` 显式优先，缺省注入 clock（默认 SystemClock，naive datetime 由 `ensure_utc` 拒 NAIVE_DATETIME）；`software_version` 复用 `_record_for`（030 助手）取 `uav_gpr.__version__`。
- **D7 raw 不变与存档完整**：输入 bytes-backed 不可写（core 保证），padded/response 均为新数组，输出经 core 构造防御拷贝为 never-writable 快照；测试断言输入内容前后全等、输出 writeable=False、写入抛 ValueError。
- **D8 显示时窗（AGENTS §8 两概念分离）**：`DisplayCropConfig(start_s,end_s)` 纯值对象（bool/非数值/NaN/Inf/负 start/end<start → INVALID_ARGUMENT/OUT_OF_RANGE）；`DisplayTimeWindowView.for_scan` 用 searchsorted 解析索引（越出存档轴尾 → OUT_OF_RANGE 不静默钳制；两样本间空窗 → INVALID_ARGUMENT；零宽恰命中样本 → 1 样本）；视图属性返回的是**存档缓冲本身的只读切片**（指针算术断言 alias 同一内存，无拷贝），构造视图不改 history、不改存档字节（快照比对测试）；绑定 kind≠time_base 的 scan → PROCESSING_DOMAIN_MISMATCH。
- **D9 黄金口径**：黄金 = ①冻结参考源 ifft.py SHA-256 `9496288e…297a`（t1 对拍 manifest 一致）+ `_time_stage_common.py e0c201b5…3c81`；②其网格+补零+斜坡算法 2026-09-05 在本 venv 独立重算的内嵌字面量（64 点轴前 8 样点 + 输出前 8 复数）；③同公式独立转写的整缓冲 bit-exact 比对；④bin 对齐（offset=0）情形与直接 `np.fft.ifft(padded)` 逐位相等。三方交叉钉死数学无偷换。

## 6. 测试矩阵（46 项，失败测试优先）

1. 协议合规：isinstance ProcessingStage、名称/版本/域集合精确；parameters 单位键与非宣称键。
2. 网格数学：默认路径 df/first_bin/offset/fft_size/轴长；bin 对齐 offset=0；round-half-even 半 bin；显式 fft_size 规则（2 的幂/容量）；oversampling 非法参数矩阵（0/负/bool/float/str/None）。
3. 轴拒绝矩阵：非均匀（context 容差自证）、容差内边缘接受、重复、递减、负频、NaN/Inf、单点。
4. 黄金对拍：轴头字面量 + 输出头部字面量 + 整缓冲独立转写 bit-exact + bin 对齐直接 np.fft.ifft 逐位相等。
5. 域链：RAW/CALIBRATED/FILTERED 三种合法前驱各自 record.input_domain 正确；time_base/time_processed 前驱 → PROCESSING_DOMAIN_MISMATCH；bandpass→ifft 双 stage 独立性（两记录 + 数值 == 手工 padded 期望）。
6. 重复 stage：真实路径（自身输出再进 → 域门拒）+ core 唯一性隔离探针（临时替换 pairwise 跳过链检，finally 恢复，030 先例）证明改 version 不绕过。
7. history：单条追加、旧 history 不动、to_dict/from_dict 往返、canonical JSON 关键子串、时钟注入与 naive 拒绝。
8. 向量化：双通道 == 各单通道（含 skew 通道线性探针）；3-trace scan == 逐 trace sweep 批处理；shape (trace,channel,time)、dtype complex128；T=1/Δf 周期恒等式。
9. raw 不变：输入内容前后全等、输入/输出 writeable=False、写输出抛 ValueError、metadata 透传。
10. 显示裁剪：只读别名（内存指针算术证明不拷贝）、边界（全窗/零宽命中/空窗拒/越界拒不钳制）、config 非法矩阵、序列化、不改 history/存档、拒绑 time_processed。
11. 排除守卫：模块源码无 depth/velocity/distance/speed_of_light、公共面不含 bandpass 符号、"resolution" 仅出现在否定键。
