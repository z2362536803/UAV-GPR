## 4. 设计决策（D1–D8）

- **D1 纯函数式边界（parser 语法层 / 组装语义层分离）**：`parse_nmea(line)` 只做语法解析，输出不可变结构化结果 `GgaResult`/`RmcResult`（保留语句内容，含 quality 0 时的坐标）；`assemble_gnss_fix(gga, received_utc, received_monotonic_ns, rmc=None, trusted_date=None)` 应用语义规则（quality 0 丢弃坐标、RMC status=A 才提供日期/速度/航向、nmea_utc 组合）并产出 `GnssFix`。**接收时刻由调用方注入**（ISSUE-025 reader 职责），parser/组装器不读时钟、不读串口、不缓存——本机接收时间绝不冒充 NMEA 时间（AGENTS.md §5、GNSS.md §2）。模块仅依赖 stdlib + `uav_gpr.core`（enums/errors/gnss/timeutil）。
- **D2 结构化错误模型**：`NmeaErrorReason`（StrEnum：`bad_checksum`/`missing_checksum`/`line_too_long`/`non_ascii`/`not_a_sentence`/`bad_talker`/`unsupported_sentence`/`too_few_fields`/`malformed_field`/`out_of_range`/`unsupported_fix_quality`）；`NmeaError(DomainError)`，code=`ErrorCode.INVALID_ARGUMENT`，context 含 `reason`（+ 可选 `field`/`index`/`expected`/`got`），JSON-safe、消息 ASCII 静态模板（不嵌入原始输入）。坏 checksum/缺失 checksum/超长/非 ASCII/非法字段/越界/不支持 fix quality **全部拒绝**（fail-closed），绝不降级为 None 或 0。
- **D3 行级守卫**：`MAX_NMEA_LINE_LEN = 256`（超长 → `line_too_long`）；先 `rstrip("\r\n")`（容忍行尾 CR/LF）；非 ASCII（`not line.isascii()`）→ `non_ascii`；不以 `$` 开头 → `not_a_sentence`；必须含 `*` + 2 位十六进制 checksum（缺失 → `missing_checksum`，非十六进制 → `malformed_field`）；checksum = `$` 与 `*` 之间字符 XOR（大小写不敏感比较）。
- **D4 字段语义与 fix quality 映射**：GGA fix quality：`0→INVALID`（无 fix）、`1→GPS_FIX`、`2→DGPS`、`4→RTK_FIXED`、`5→RTK_FLOAT`、`6→ESTIMATED`、`8→SIMULATED`；**`3`（PPS）与 `7`（manual）在 `GnssFixQuality` 无对应成员 → 结构化拒绝 `unsupported_fix_quality`（fail-closed，不误标为其他语义）**；quality 字段为空/缺失 → 拒绝；quality ∈ 有效集但 lat/lon 缺失 → 拒绝（`malformed_field`）。quality 0 时语句坐标在**组装层**丢弃（`GnssFix` invalid 不得携带坐标——模型 `__post_init__` 强制，双保险），`invalid_reason=NO_FIX`。空字段（lat/lon/sats/hdop/msl/geoid/速度/航向/日期/时间）→ **None 而非 0**。lat/lon：`ddmm.mmmm`（lat 4 位整数）/`dddmm.mmmm`（lon 5 位整数），分钟部分 `< 60`，`|lat|≤90`、`|lon|≤180`，S/W 取负；sats 0–99；HDOP 0–99.9（模型界）；course `0 ≤ x < 360`；time hh≤23/mm≤59/ss<60（`ss==60` 闰秒按越界拒绝，fail-closed，计划记录）；日期为合法日历日。
- **D5 单位与 MSL/AGL**：knots→m/s 用精确常数 `1852.0/3600.0`；GGA 高度/水准面分离单位字段必须为 `M` 或空，其他单位 → 拒绝（`malformed_field`）；高度保存为 `GnssFix.altitude_msl_m`（字段名即 MSL 语义）、水准面分离为 `geoid_separation_m`——**任何位置不标注/不换算 AGL**（GNSS.md §6、AGENTS.md §5：MSL、椭球高与 AGL 不得混用，无 AGL 来源不得推算）。
- **D6 RMC 日期 + GGA 时间组合与跨午夜策略**：仅 `status=A` 的 RMC 提供日期/速度/航向（V 语句数据在组装层不采用）；`combine_nmea_utc(gga_time, rmc, trusted_date)`：RMC 日期存在 → 以 GGA 日内秒与 RMC 日内秒比较，**12 小时容差**：差 `< −12h` → 日期 +1 天（跨午夜），`> +12h` → 日期 −1 天，否则同日；RMC 无日期（或 V）→ 用调用方注入的 `trusted_date`（GNSS.md §2「必要时与 RMC 日期或可信系统日期组合」）；两者皆无 → `nmea_utc=None`（模型允许）。RMC 单独（无 GGA）不产出 GnssFix（fix quality 无法得知——不伪造）。2 位年份翻转：`80–99→19xx`、`00–79→20xx`；非法日历日期（如 310294）→ 拒绝。
- **D7 talker-independent**：语句 ID 前 2 字符为 talker（`[A-Z0-9]{2}`，GP/GL/GA/GN/GB/GQ 等一律接受），后 3 字符 `GGA`/`RMC` 分派；其他语句 → `unsupported_sentence`；字段数不足（GGA < 7 段、RMC < 7 段）→ `too_few_fields`；多余尾字段容忍。
- **D8 黄金向量**：夹具全部为**匿名/合成**语句（不来自参考仓库，符合「用匿名/合成 NMEA 覆盖…」）；checksum 由独立脚本预计算后**硬编码**进测试（经典样例 `$GPGGA,123519,...*47` 交叉验证）；期望数值手工推导（如 4807.038N → 48.1173°，022.4 knots → 11.523… m/s）。

## 5. 测试矩阵（失败测试优先，先红灯后绿灯；全部纯函数、无硬件、无固定 sleep）

1. 正常 GGA（GPS fix）：`$GPGGA,123519,4807.038,N,01131.000,E,1,08,0.9,545.4,M,46.9,M,,*47` → talker `GP`、`utc_time=12:35:19`、lat `48.1173`（approx）、lon `11.5166667`（approx）、`fix_quality=gps_fix`、sats 8、hdop 0.9、msl 545.4、geoid 46.9、单位 M。
2. 正常 RMC（status A）：日期 `230394→1994-03-23`、speed `022.4 knots → 022.4×1852/3600 m/s`（approx）、course 84.4。
3. 南/西半球：S → 负 lat、W → 负 lon（含 GGA 与 RMC 各一）。
4. 不同 talker：GP/GL/GA/GN 全部解析成功。
5. 坏 checksum（篡改 1 字符）→ `NmeaError(bad_checksum)`；缺失 `*` → `missing_checksum`。
6. 无 fix（quality 0）：parse 成功（保留语句坐标）；`assemble_gnss_fix` → `valid=False`、`invalid_reason=no_fix`、lat/lon None、sats/hdop/msl 保留。
7. 空字段 → None 非 0：空 sats/hdop/msl/geoid/速度/航向/日期/时间。
8. 越界 → `out_of_range`：lat 分钟 60、sats 100、hdop 100、course 360、time 24:00:00、秒 60、非法日期 310294。
9. 跨午夜：RMC `235959/230394` + GGA `000001` → `nmea_utc == 1994-03-24T00:00:01Z`；反方向（GGA `235959`、RMC `000001/230394`）→ 前一日 `1994-03-22T23:59:59Z`；同日无偏移。
10. RMC 日期缺失 → `nmea_utc=None`（无 trusted_date）；注入 `trusted_date` → 组合成功；RMC status V 不提供日期/速度/航向。
11. 行级守卫：非 ASCII → `non_ascii`；>256 字符 → `line_too_long`；无 `$` → `not_a_sentence`；坏 talker → `bad_talker`；未知语句（`$GPGSA`）→ `unsupported_sentence`；字段不足 → `too_few_fields`；空 quality → `malformed_field`；高度单位 `F` → `malformed_field`。
12. fix quality 3（PPS）/7（manual）→ `unsupported_fix_quality`。
13. 组装：valid fix → `GnssFix` 全字段正确、`valid=True`、`invalid_reason=None`、`received_utc`/`received_monotonic_ns` 透传、`nmea_utc` 组合正确、`to_dict/from_dict` 往返一致；quality 0 → 见 6；`received_utc` naive → GnssFix 拒绝（NAIVE_DATETIME，模型守卫对拍）。
