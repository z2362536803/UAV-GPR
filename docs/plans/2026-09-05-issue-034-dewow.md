## 4. 设计决策（D1–D9）

- **D1 stage 契约与域映射**：`DewowStage` 结构化实现 030 冻结的 `ProcessingStage` Protocol（尾部 `assert isinstance(...)` 静态防漂移，031 先例）：`stage_name="dewow"`（与参考及 031 测试 fixture `_archived_result` 中既有名称一致的稳定 snake_case token）、`stage_version="1.0"`、`input_domain=frozenset{TIME_BASE, TIME_PROCESSED}`、`output_domain=TIME_PROCESSED`。空 history ⇒ `_input_domain_of` 给 FREQUENCY_RAW ⇒ 不在允许集 ⇒ `PROCESSING_DOMAIN_MISMATCH` 拒（非法顺序第一道门）；频域中间域/TIME_PROCESSED 之外的末域同样被 stage 域门拒。追加走 `ProcessingHistory.append`（同 history `stage_name` 唯一由 core fail-closed 强制，bump version 不绕过 ⇒ "重复 Dewow 拒绝"第二道门）。输入容器限定 `TimeDomainScan`（core 无单 sweep 时域模型，031 D2 同构），非 scan ⇒ TypeError。
- **D2 窗口参数命名（t1 §3.3-2 决策点定稿）**：本项目 `time_axis_s` 单位为秒（core/time_domain.py L659），团队口径"窗口秒→样本"——构造签名 `DewowStage(window_s: float = DEFAULT_DEWOW_WINDOW_S)`，`DEFAULT_DEWOW_WINDOW_S: Final = 4e-9`（数值上等于参考默认 4.0 ns，迁移其语义而非单位外壳）。`window_s` 入场校验：bool/非实数标量/非有限/≤0 ⇒ `INVALID_ARGUMENT`（对齐参考 `_validate_window_ns` 姿势）。dt 从输入时间轴推导、不由调用方传入（参考同文）。
- **D3 dt 推导（`derive_sample_interval_s(time_axis_s) -> float`）**：≥2 点（否则 `INVALID_ARGUMENT`，消息含点数）；严格递增哨兵 `np.diff>0`（`NON_INCREASING_AXIS`，防御性双检——core 已保证但 dewow 自洽不依赖）；有限性（`NON_FINITE_AXIS`）；取 `median(diff)`，最大偏差 > `|dt|·DEWOW_AXIS_TOLERANCE_REL(1e-6)` ⇒ `NON_UNIFORM_AXIS` 拒（等间隔假设显式补闸，容差与 031 IFFT_GRID_TOLERANCE_REL 同量级同姿势）。
- **D4 秒→样本舍入链（`window_samples_for(window_s, dt_s, n_time) -> int`，逐条钉死参考顺序）**：`samples = int(round(window_s / dt_s))` → `max(1, ·)` → 偶数则 `+1` 转奇 → `== 1` 拒（`INVALID_ARGUMENT`，提示增大 window_s，context 含 window_s/dt_s/n_time）→ `> n_time` 拒（`INVALID_ARGUMENT`，提示减小 window_s）。round 采用 Python IEEE round-half-to-even 语义并有半样本边缘测试钉死（031 先例精神）。窗口恒为奇数 ≥3 ≤n_time。
- **D5 数值核心（`centered_moving_mean(data, *, axis, window, padding="reflect")`，参考 verbatim 迁移）**：moveaxis → pad `(half,half)` 沿目标轴（mode 固定 `"reflect"`，不接受其它值——边界策略是契约不是选项）→ `np.cumsum(dtype=complex128)` 前置零切片 → `cum[window:] - cum[:-window]` → `/window` → moveaxis 复原。O(N)、复数实/虚部各自累加（等价 real/imag 独立处理），输出 shape/dtype 与输入一致。守卫：window 必须奇数 ≥3、data 复数 ndarray、axis 长度 ≥ window（越界 INVALID_ARGUMENT）。该函数是本 Issue 唯一滑动均值实现——031 未迁移此工具（当时仅需骨架 M4 项），dewow 按迁移规则"提取契约"内嵌于 `dewow.py`（inScope 无 common 模块路径，扁平化决策记录于此）；035 flat 需要 edge/trace 轴变体时再评估是否抽公共模块。
- **D6 入场守卫与非法顺序（对应验收"重复 Dewow 与非法 history 顺序拒绝"）**：①history 末域 ∈ {TIME_BASE, TIME_PROCESSED}（D1 域门）；②history 任一记录 `stage_name=="dewow"` ⇒ 显式 `INVALID_ARGUMENT` 拒（早于 core append 兜底、给出 dewow 专属消息——stage 层第一重复门；core 唯一性为第二道，探针证明 bump version 不绕过）；③history 已含 `flat_reflection_filter` ⇒ `PROCESSING_DOMAIN_MISMATCH` 拒（固定推荐顺序 dewow → flat_reflection_filter，参考 `_reject_flat_before_dewow` verbatim 语义；flat 本身属 035 不实现，本守卫只挡逆序）；④`source.data` 非有限（NaN/Inf，real/imag 任一）⇒ `NON_FINITE_AXIS` 拒（入场补闸，core readonly 不查有限性）；⑤shape 双检：`data.ndim==3` 且末维 == `time_axis_s.size`（core 构造已拦，stage 自洽再验）；⑥kind/history 一致性由 core `_validate_history_kind` 在入场即拒（time_base 快照挂错历史不可能溜过）。合法前驱验证：TIME_BASE→TIME_PROCESSED、TIME_PROCESSED→TIME_PROCESSED 两 hop 均在 core `_ALLOWED_TRANSITIONS`（L117-118）已开。
- **D7 输出重建与不可变**：`filtered = source.data − local_mean`（新数组）→ 新 `TimeDomainScan(channels/time_axis_s/metadata 全量透传, kind=TIME_PROCESSED, history=new_history)`（core 构造防御拷贝置 never-writable）；返回 031 的姊妹类 `TimeDomainStageResult(source, history, domain=TIME_PROCESSED)`（三字段形状同 030 StageResult，source 运行时限定 TimeDomainScan——正是本阶段所需）。输入 source/data bytes 前后全等（测试断言）。
- **D8 record parameters（JSON-safe、单位显式、可复现）**：经 `_record_for(stage_name="dewow", stage_version="1.0", input_domain=末域, output_domain=TIME_PROCESSED, executed_utc=stamp)`；parameters = `{operation:"subtract_centered_moving_average", axis:"time_last", padding:"reflect", window_s, dt_s, window_samples, time_sample_count, reference_source_sha256:{dewow.py, _time_stage_common.py}}`——最后两项把冻结参考源哈希带进每条 provenance（黄金对拍口径 D9①，审计端无需外部表）。`executed_utc` 显式优先（naive ⇒ `ensure_utc` 拒 NAIVE_DATETIME），缺省注入 clock（默认 SystemClock 一次读取，无 sleep）；software_version 取 `uav_gpr.__version__`（`_record_for` 内置）。
- **D9 黄金口径（三方交叉，031 先例）**：①冻结参考源 SHA-256：`dewow.py = eb6690e7fabf0bc80e051831ab6264e6e6d112b6568fb6dc30556a3a7f030e2c`、`_time_stage_common.py = e0c201b55acbaece0edb1546bbb8a00492874bb79fb9caf789d5ba416d333c81`（t1 §2 与 manifest.json 实测对拍一致，写入测试模块 docstring 与 record parameters）；②参考 `_centered_moving_mean` verbatim 移植体 2026-09-05 在本 venv 独立重算的内嵌字面量（场景 A：n=8 W=3 单道复数；场景 B：2×2×6 全缓冲 mean/out 展平——输入缓冲本身也钉为 float64 字面量以杜绝生成器/消费者公式漂移；场景 C：n=4 短数组边界 reflect），canonical golden JSON（sources + A_mean_re + B_out_im + C_out）SHA-256 = `e5e2486180697b7338c2e96137714aa18a76d1ad6ea03b34c50c79b1852231b8` 由测试逐位钉死；③独立转写比对：朴素 O(N·W) reflect-index 循环在场景 B 缓冲上整缓冲 **bit-exact**；np.convolve 转写在求和顺序噪声内 allclose(rtol=1e-12, atol=0)（IEEE 加法不可结合性使逐位等式仅在部分浮点域成立——dyadic 四分之一网格探针上三方全部 bit-exact，另设 skew 平移不变性在该 dyadic 探针上 bit 级断言、一般缓冲上 <1e-12 容差断言）。生成脚本置于工作区外（/tmp/dewow_gold），仓库零污染。

## 7. 测试矩阵（失败测试优先；覆盖 captain 指派全部维度）

1. 协议合规：isinstance ProcessingStage；名称/版本/输入域 {time_base,time_processed}/输出域 time_processed 精确；`TimeDomainStageResult.domain=TIME_PROCESSED`；非 scan 输入 TypeError；window_s 非法矩阵（bool/str/NaN/Inf/0/负）INVALID_ARGUMENT。
2. 常量场：全常数道（多通道不同常数）输出 ≈ 0（减自身均值，abs max < 1e-12 相对界）；互不串扰。
3. 脉冲：δ 道 ⇒ 输出 = δ − (1/W)·reflect_pad(δ)（首/尾窗边界手算钉死）。
4. 复数等价：`dewow(a+bj).real == dewow(a)` 且 `.imag == dewow(b)` 逐位；线性 skew 复平面 dcm（dewow(z)≡z−z 全零指纹）。
5. 短数组/窗口边界：n_time=1（轴无法推 dt）拒；window 使 samples==1 拒（消息含"增大"指引）；window>n_time 拒（含"减小"指引）；偶数 window_s 转奇链、round-half-even 半样本边缘；恰等 n_time 奇数窗通过；非均匀/递减/含 NaN 轴/单点轴拒绝矩阵（D3 各码）。
6. 多通道/多 trace：双通道各自处理互不影响（skew 通道线性探针）；scan == 各 trace 单独批一致；shape/dtype complex128/axis 不变；metadata per-trace 透传（有/无两种）。
7. history 语义：空 history（RAW 前驱）拒；频域末域前驱拒；重复 dewow 双门（真实输出再进 INVALID_ARGUMENT + core 唯一性隔离探针 bump version 仍拒）；flat-before-dewow 拒（合成含 `flat_reflection_filter` 记录的合法链）；record 字段全检（input/output/software/stamp/parameters 键集合与 reference hashes）；to_dict/from_dict JSON-safe 往返全等；下游链（time_processed→time_processed 再 dewow 域拓扑合法但被 stage 重复门拒——两门分工断言）。
8. 输入不变性：source.data/time_axis bytes 前后全等 + writeable False；输出新对象、write-protected、写入抛 ValueError；history 旧对象不动、append 返回新实例。
9. 黄金三方（D9）：场景 A/B/C 内嵌字面量 exact equality；朴素独立转写与 np.convolve 双路整缓冲 bit-exact；golden canonical SHA-256 复核。
10. 性能 smoke：512×2×1024 complex128（≈16.8 MB）单次 apply 墙钟 < 10 s（宽松界，证明确定性 O(N) 累积和无逐窗 Python 循环；pytest 标记非 slow/非硬件）。
11. 排除守卫：AST/源码级——模块无 `rebar_inspector`/`storage`/`acquisition`/Qt import、无 `flat`/edge-padding 计算路径符号（`"edge"` 仅允许出现在注释/docstring 说明 035 归属）、公共面不含 depth/velocity/display 符号。
