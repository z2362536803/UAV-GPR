# ADR-0001：地面端为主的双端架构

- 状态：Accepted
- 日期：2026-08-21

## 背景

旧 UAV-GPR 在空中端和地面端都堆叠了采集、处理、绘图和控制 UI，增加机载资源消耗、状态重复和现场操作复杂度。新产品的主要操作者使用较大笔记本地面端。

## 决策

地面端承担任务设计、校准、处理、显示、GNSS 地图、主存档、回放和诊断。空中端只承担硬件/GNSS 接入、冻结任务执行、本地可靠保存、状态上报、回传和安全停止。

共享领域模型与协议，但地面/空中 application 和 UI 不互相导入。空中 UI 不提供 B-scan、地图、校准和处理。

## 后果

- 地面端成为主要产品体验和复杂度所在地。
- 断网时空中端仍需独立安全运行，不能依赖地面 UI 维持采集。
- 任务配置和状态协议必须足够明确，不能共享进程内对象。
- 空中端更容易做无显示器部署和资源控制。
