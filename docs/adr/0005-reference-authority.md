# ADR-0005：参考项目权威范围

- 状态：Accepted
- 日期：2026-08-21

## 背景

钢筋仪项目在分层、LibreVNA、校准、处理、存储和 UI 上更成熟。旧 UAV-GPR 虽包含 GNSS 和 HM30 现场经验，但主窗口、每道文件、协议和显示存在性能/一致性风险。无选择复制会把问题带入新项目。

## 决策

钢筋仪项目是 core、LibreVNA 采集、校准、处理、`.rcscan`、模拟/回放和 B-scan UI 的主要参考。旧 UAV-GPR 的生产代码只对白名单 GNSS parser/reader/matcher 开放；HM30 文档只作为需复核的部署事实。

旧 UAV-GPR 主窗口、传输类、NPZ 协议、CSV/NPZ 存储、Matplotlib B-scan、在线地图和校准/处理禁止迁移。每次迁移记录 branch/HEAD/status、源文件 SHA256、目标模块和测试。

## 后果

- 需要重新实现可靠传输和离线地图，而不是最快复制旧代码。
- 迁移工作更可审计，算法可信边界清楚。
- 两个参考仓库的脏工作树不能被当作稳定版本，必须按文件冻结。
