# ADR-0003：菜单式地面主界面和右侧 GNSS 地图

- 状态：Accepted
- 日期：2026-08-21

## 背景

旧 UAV-GPR 地面 UI 常驻元素过多，数据区域被设置、日志和控制面板挤压。新地面端主要运行在 1440×900 或 1920×1080 笔记本，并需要同时理解雷达剖面与空间轨迹。

## 决策

地面主界面顶部为单行菜单；设置、校准、处理和诊断使用菜单/对话框。中央左侧上下显示 S11/HH 与 S22/VV B-scan，右侧显示 GNSS 地图，默认约 68:32 且可拖动/折叠。底部只保留单行关键状态。

B-scan 和地图按 `trace_uid` 双向联动。地图离线可用并支持无底图降级，不迁移旧在线 Leaflet 页面。A-scan、频域和日志作为按需窗口。

## 后果

- 主界面更聚焦数据，但所有菜单状态和对话框需有一致应用状态模型。
- 地图和双 B-scan 同屏需要性能与 DPI 测试。
- GNSS 地图属于数据视图，不违反“主界面只显示数据”的原则。
- 地图渲染技术仍需独立 ADR 决定。
