# HM30 部署与现场验证

版本：0.1
状态：部署计划；参数源自旧项目资料，正式使用前必须按实物和最新版手册复核

## 1. 计划拓扑

```text
Air: LibreVNA + GNSS -> air computer -> HM30 air unit
                                           )) radio link ((
Ground laptop <- Ethernet <- HM30 ground unit
```

应用层由空中端主动连接地面端。HM30 提供普通 IP 链路，不承担数据持久化、ACK 或补传语义。

## 2. 示例网段

旧参考资料给出的 HM30 默认网段为 `192.168.144.0/24`。项目示例暂定：

| 设备 | 示例地址 |
|---|---|
| HM30 air | `192.168.144.11` |
| HM30 ground | `192.168.144.12` |
| air computer | `192.168.144.30` |
| ground laptop | `192.168.144.111` |
| protocol port | `8765` |

这些值是部署样例，不是软件硬编码。接入实际设备前核对 IP 冲突、网关需求、手册版本和组织网络策略。

## 3. 配置管理

- 从 `config/*.example.toml` 复制本地配置，不修改提交的示例来存现场值。
- 设备 ID、地址、端口、存储根目录和认证信息在部署清单中登记。
- 密钥不写日志、不提交 Git，诊断包默认脱敏。
- 启动时打印/显示配置摘要和来源，但隐藏秘密。
- 地面端防火墙规则只开放所需接口/端口，并在现场前预演。

## 4. 连通性验收

按层检查：

1. 网卡链路和固定 IP；
2. 地面/空中电脑分别可达本侧与对侧 HM30；
3. 空中端可达地面监听地址/端口；
4. 协议 hello/ack、版本和设备身份正确；
5. 心跳、命令、测试 trace 和 ACK；
6. 限速、暂时遮挡、断线和自动重连；
7. 重连后 outbox 对账与补传。

诊断按钮/工具只能报告结果，不能在未确认时自动重配系统网卡或关闭防火墙。

## 5. 空中存储

- 空中端本地磁盘是正式数据副本，不是临时缓存。
- 起飞前检查可写性、余量、预计任务体积和保留策略。
- 磁盘低水位先告警；达到安全停止阈值时不再发起新 sweep，完成当前安全写入并结束任务。
- 网络不可用时继续写盘和积累 outbox；磁盘不可写时停止采集。
- 落地后可通过同一协议或受控离线方式核对，不直接移动正在写的 partial 文件。

## 6. 供电和安装

旧 HM30 资料提到空中端约 3S～6S 供电、平均与峰值功耗差异明显；具体电压、引脚和峰值必须以当前实物版本手册复核。计划要求：

- HM30 与 LibreVNA/采集电脑尽量使用隔离良好的供电路径；
- DC-DC 按峰值、温升和飞行时间留余量；
- 网线、USB、RF 馈线分开布线并根据测试加磁环；
- HM30/GNSS/GPR 天线、LibreVNA 和馈线保持实测决定的安全距离；
- 天线安装考虑碳纤维/金属遮挡、姿态和散热。

旧资料中的 20 cm、50 cm 或 1 m 等建议只能作为实验起点，不作为未验证的产品保证。

## 7. 电磁干扰对照

正式飞行前，在相同雷达/天线/场景配置下完成：

| 组 | HM30 | 数据负载 | 目的 |
|---|---|---|---|
| A | 关闭 | 无 | 雷达基线 |
| B | 开启 | 空闲 | 载波/供电影响 |
| C | 开启 | 正常 trace | 实际工作影响 |
| D | 开启 | 高负载 | 最坏链路/供电影响 |

每组保存足量 raw 和 GNSS，比较频域噪声、固定尖峰、A/B-scan 纹理、GNSS fix、trace 缺失、供电纹波和温度。报告中记录位置、距离、天线方向、线缆和固件。

## 8. 时钟

空地墙钟用于审计，但任务调度由空中单调时钟完成。部署前检查时区和 UTC；协议记录双方时间和 RTT 估计。系统钟跳变不得改变 trace index 或调度 deadline。

## 9. 现场启停顺序

计划顺序：

1. 检查空中存储、电源、天线和线缆；
2. 启动 HM30 和两台电脑，完成链路诊断；
3. 启动空中服务，确认 VNA/GNSS/磁盘；
4. 启动地面端，连接并创建任务；
5. 校准/空采检查，短采预览和完整性确认；
6. 正式任务；
7. 正常结束、对账和双副本验证；
8. 关闭应用后再断设备电源。

应急情况下优先飞行和人员安全；软件保留 partial 并在落地后恢复。

## 10. 待验证清单

- HM30 当前硬件版本、手册、频段、功耗、尺寸、接口和 IP；
- 目标空中电脑与磁盘持续写入/温度；
- 防火墙、网卡节能和 Windows 自动更新策略；
- 最大任务距离/姿态下吞吐和断线恢复；
- HM30 对 GPR 与 GNSS 的电磁影响；
- 飞行平台载荷、电源与法规要求。
