# 产品需求

版本：0.1（初始化基线）
状态：已决定的产品方向，功能尚未实现

## 1. 产品定位

UAV-GPR 是一套面向无人机搭载 LibreVNA 探地雷达的双端软件。操作者在地面笔记本完成任务配置、监视、校准、处理和数据检查；机载电脑在网络可能不稳定的条件下可靠完成采集并保留原始数据。

## 2. 目标用户

- 外场操作员：配置任务、启动/停止采集、监看剖面和位置、确认数据完整性。
- 雷达工程师：完成 OSL/空采参考、调整处理链、检查 A/B-scan 和导出数据。
- 设备维护人员：诊断 LibreVNA、GNSS、HM30、磁盘和空地数据一致性。
- 研发人员：使用模拟器、回放和契约测试迭代，不依赖每次接入真机。

## 3. 核心用户流程

### 3.1 任务前

1. 地面端连接空中端并查看 VNA、GNSS、磁盘和链路状态。
2. 创建新任务，配置扫频、通道、物理时窗、显示时窗、采集间隔和说明。
3. 加载兼容 `.rcal/.rcbg`，或通过菜单进入校准/空采向导。
4. 检查参数摘要与预计数据量，冻结并下发任务配置。

### 3.2 采集中

1. 空中端先写本地 `.partial.rcscan`，再将逐道原始数据加入持久化 outbox。
2. 地面端接收、校验、保存、处理并更新左侧双 B-scan。
3. 右侧 GNSS 地图显示无人机当前位置、轨迹和当前道位置。
4. 底部状态栏显示链路、空中端、VNA、GNSS、任务、道数、丢失和待同步状态。
5. 网络中断时空中端继续采集；地面端明确显示离线与数据滞后。

### 3.3 任务后

1. 空中端完成文件并发送任务结束清单。
2. 地面端对账、请求缺道补传并核对逐道原始哈希。
3. 操作者查看完整性报告、回放、调整显示/处理参数并导出。
4. 空中端副本仅在地面端验证完成并由用户确认后清理。

## 4. 功能需求

| 编号 | 需求 |
|---|---|
| FR-001 | 地面端能够发现/连接单台空中端并展示明确连接状态。 |
| FR-002 | 地面端能够创建、校验、冻结并下发采集任务。 |
| FR-003 | 空中端能够通过单一 LibreVNA 生产路径采集至少 S11，并为 S11/S22 双反射通道保留契约。 |
| FR-004 | 支持配置频率范围、点数、IFBW、通道、物理时窗、显示时窗、采集数量和采集间隔。 |
| FR-005 | 空中端用单调时钟执行间隔调度并记录目标/实际间隔和误差。 |
| FR-006 | GNSS 独立读取，保存定位质量，并按 sweep 中点匹配每一道。 |
| FR-007 | 空中端每一道先可靠保存，再进入持久化发送队列。 |
| FR-008 | 地面端校验、去重、增量保存，只有持久化成功后才 ACK。 |
| FR-009 | 断线重连后自动对账并补传，哈希冲突不得静默覆盖。 |
| FR-010 | 空地正式数据均使用 `.rcscan` v2 家族，空中副本可独立回放。 |
| FR-011 | 地面端支持 `.rcal/.rcbg` 的加载、兼容性检查、采集和应用。 |
| FR-012 | 处理链由独立阶段组成，保留原始数据、参数、版本和历史。 |
| FR-013 | 地面主界面左侧显示双 B-scan，右侧显示 GNSS 地图。 |
| FR-014 | B-scan 道与地图位置能够按 `trace_uid` 双向联动。 |
| FR-015 | 设置、校准、处理和诊断放入顶部菜单或对话框，不常驻主数据显示区。 |
| FR-016 | 地面端可打开、恢复、回放、重新处理和导出已有任务。 |
| FR-017 | 空中端 UI 仅提供必要状态、日志入口和安全停止。 |
| FR-018 | 提供模拟采集、GNSS 回放、链路故障注入和 `.rcscan` 回放能力。 |
| FR-019 | 提供空地副本、缺道、重复、哈希和文件完整性诊断。 |

## 5. 非功能需求

- **数据优先**：UI 或网络故障不能导致已经完整采集的 sweep 无记录地丢失。
- **可恢复**：进程崩溃或掉电后保留 `.partial.rcscan`，可只读检查并显式恢复。
- **可追溯**：配置、校准、处理、时间、GNSS、软件版本和错误均可追踪。
- **离线可用**：除可选地图资源外，核心采集、存储、处理、回放和轨迹显示不依赖互联网。
- **可测试**：无真机时可以覆盖主要业务和故障路径。
- **长时稳定**：队列、历史和地图渲染有界，不随任务长度产生不可控内存增长。
- **安全失败**：磁盘失败、配置不兼容、数据冲突和不支持的 schema 必须停止或拒绝，不降级成“看似成功”。

## 6. 明确不在首个可用版本范围

- EMI、联合反演、自动目标识别和 AI 解释。
- 无人机飞控、航线规划和自动驾驶控制。
- 多空中端同时接入。
- 云端同步和多地面站分发。
- 未经标定的自动深度结论。
- 在线账户、权限平台和远程固件升级。
- 把视频图传纳入本软件协议。

这些能力只能通过后续需求和 ADR 引入，不得为了“预留”而污染首版核心路径。
